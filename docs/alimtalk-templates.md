# 알림톡 템플릿 (Solapi 등록용)

> 코드가 보내는 치환 변수와 **정확히** 일치해야 한다. 변수명이 하나라도 어긋나면 그
> 템플릿만 발송이 실패하고 SMS 로 폴백된다(조용히 — 화면에는 아무 표시도 안 난다).
> 원본: `apps/api/src/notification/services/notification.service.ts`

## 등록 전 알아둘 것

- **본문에 `[Pawlog]` 같은 머리말을 넣지 않는다.** 알림톡은 카카오 채널 프로필명이 위에
  자동으로 붙는다. SMS 폴백 문구에만 `[Pawlog]` 가 붙어 있는데, 그건 문자에서 발신자를
  알 방법이 그것뿐이기 때문이다.
- **변수만으로 시작하거나 끝나는 문장은 반려**되기 쉽다. 고정 문구로 감싼다.
- **정보성만.** 이벤트·할인·"갱신해주세요" 같은 유도 표현은 광고성으로 분류될 수 있다.
  그래서 아래 잔여횟수 템플릿은 사실만 남겼다(SMS 폴백 문구와 다른 이유).
- **채널 추가 유도 문구 금지.**

---

## 1. 등원 알림

- env: `SOLAPI_TEMPLATE_CHECK_IN`
- 변수: `#{petName}` `#{time}`

```
#{petName}(이)가 #{time}에 등원했습니다.

오늘도 안전하게 돌보겠습니다.
```

---

## 2. 하원 + 알림장 (⚠️ 링크 포함)

- env: `SOLAPI_TEMPLATE_CHECK_OUT_REPORT`
- 변수: `#{petName}` `#{time}` `#{reportToken}`

```
#{petName}(이)가 #{time}에 하원했습니다.

오늘 하루의 알림장이 준비되었습니다.
아래에서 확인해 주세요.
```

**버튼**: 웹링크 · 버튼명 `알림장 보기`

```
https://<서비스 도메인>/r/#{reportToken}
```

> ⚠️ **전체 URL 은 변수로 쓸 수 없다.** 도메인은 버튼에 고정으로 등록하고 **가변 부분인
> 토큰만** 변수가 된다. 그래서 코드가 알림톡에는 `reportToken`(토큰만), SMS 폴백에는
> `reportUrl`(전체 주소)을 각각 넘긴다 — 같은 링크를 채널별로 다른 모양으로 준다.
>
> `<서비스 도메인>` 은 실제 배포 도메인으로 바꿔 등록한다(사전등록 필요).

---

## 3. 이용권 잔여 안내

- env: `SOLAPI_TEMPLATE_REMAINING_COUNT_LOW`
- 변수: `#{remaining}`

```
등록하신 이용권의 잔여 횟수가 #{remaining}회입니다.

자세한 내용은 유치원으로 문의해 주세요.
```

> SMS 폴백에는 "이용권을 갱신해주세요"가 들어 있지만 알림톡 본문에서는 뺐다. 갱신 유도는
> 광고성으로 볼 여지가 있다. 사실만 알리고 행동은 보호자가 정한다.

---

## 4. 등원 예정 리마인드

- env: `SOLAPI_TEMPLATE_RESERVATION_REMINDER`
- 변수: `#{petName}` `#{date}`

```
내일(#{date}) #{petName}의 등원이 예정되어 있습니다.

변경이 필요하시면 유치원으로 연락해 주세요.
```

---

## 5. 사진 알림

- env: `SOLAPI_TEMPLATE_FEED_POST`
- 변수: `#{petName}` — **링크에는 변수가 없다**

```
#{petName}의 오늘 사진이 등록되었습니다.

아래에서 확인해 주세요.
```

**버튼**: 웹링크 · 버튼명 `사진 보기`

```
https://<서비스 도메인>/feed
```

> 사진 링크는 고정 주소라 치환할 것이 없다. 버튼에 주소를 그대로 등록한다.
>
> ⚠️ 다만 `/feed` 는 **로그인이 필요한 화면**이다(보호자 개인 피드). 알림장 링크(`/r/…`)와
> 달리 미가입 보호자는 이 버튼을 눌러도 볼 수 없다. 지금 구조가 그렇다는 것만 알아둔다.

---

## 6. 임시 휴무 안내 (job-060)

- env: `SOLAPI_TEMPLATE_TENANT_CLOSURE`
- 변수: `#{petName}` `#{tenantName}` `#{date}` `#{reason}`

```
#{tenantName}이(가) #{date}에 휴무하여 #{petName}의 등원이 취소되었습니다.

사유: #{reason}

다른 날로 다시 예약해 주세요.
```

> ⚠️ **이 템플릿만 "매장 → 보호자"의 취소 통보**다. 나머지는 이미 일어난 일을 알리지만
> 이건 **일어나지 않게 된 일**을 알린다 — 받지 못하면 보호자는 문 닫은 매장 앞에 아이를
> 데리고 선다. 다른 어떤 템플릿보다 폴백(SMS)이 실제로 도는지가 중요하다.
>
> `#{reason}` 은 **비어서 나가지 않는다.** 원장이 사유를 적지 않으면 코드가 `매장 사정`
> 으로 채운다(`NotificationService.notifyTenantClosure`) — 알림톡은 빈 치환 변수를
> 반려하는 경우가 있고, "사유: " 뒤가 비면 문장이 깨져 보인다.
>
> "다시 예약해 주세요"는 광고성이 아니라 **취소된 예약을 되살리지 않는다는 정책의
> 안내**다(휴무를 해제해도 예약은 복구하지 않는다 — `business-hours-and-reservations.md`
> §3.2). 이 문장이 없으면 보호자는 매장이 알아서 옮겨 줬으리라 기대한다.

## 값 형식 (코드가 넣는 실제 값)

| 변수 | 예시 | 비고 |
| --- | --- | --- |
| `petName` | `초코` | |
| `tenantName` | `해피독 유치원` | 매장 이름. 조회 실패 시 `유치원` |
| `time` | `09:30` | 24시간, `ko-KR` 2자리 |
| `date` | `8월 13일` | |
| `reason` | `설 연휴` | 미입력 시 `매장 사정` — **빈 값으로 나가지 않는다** |
| `remaining` | `3` | 숫자를 문자열로 변환해 보냄 |
| `reportToken` | `eyJpZCI6…​.abc123` | 서명 토큰. 버튼 링크 `…/r/#{reportToken}` 에 붙는다(14일 만료) |

SMS 폴백에는 전체 URL(`https://…/r/<token>`)이 본문에 그대로 들어간다 — 문자에는 버튼이
없기 때문이다. 즉 **같은 링크가 채널에 따라 다른 모양으로 나간다.**

## 등록 후 할 일

1. 발신프로필(카카오 채널) pfId → `SOLAPI_KAKAO_PF_ID`
2. 승인된 템플릿 코드 6개 → `SOLAPI_TEMPLATE_*`
3. 컨테이너 재시작 → 그때부터 알림톡 우선, 실패 시 SMS 폴백
4. **첫 발송에서 치환이 실제로 됐는지 확인한다.** 본문에 `#{petName}` 이 그대로 찍혀
   나오면 API 로 넘기는 `variables` 객체의 **키 형식**이 어긋난 것이다(아래 참고).

## ⚠️ variables 키 형식

템플릿 본문은 `#{petName}` 이지만, Solapi API 로 넘기는 `kakaoOptions.variables` 객체의
**키**도 `#{petName}` 이어야 하는지 `petName` 이어야 하는지는 문서 기준으로 확인이 필요하다.
현재 코드는 두 형태를 **모두** 실어 보내므로 어느 쪽이든 치환된다
(`solapi-client.service.ts` 의 `expandVariableKeys`).
