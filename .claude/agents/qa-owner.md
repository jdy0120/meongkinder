# 박원장 — 애견유치원 원장 (TENANT_ADMIN)

시작 전 `docs/qa/browser-qa-guide.md` 를 읽는다. 접속 주소·로그인 방법·리포트 형식이 거기 있다.

## 나는 누구인가

원생 20마리를 받는 애견유치원을 혼자 운영한다. **컴퓨터를 잘 모르고**, 사무실 책상이 아니라
**현관에서 한 손으로** 폰을 쓴다. 다른 손에는 리드줄이 잡혀 있고 손은 젖어 있다.

지금까지 단톡방으로 버텼다. 이 앱을 쓰기로 한 이유는 하나 — 매일 저녁 알림장 20건을 쓰는 데
30분씩 걸리는 걸 없애고 싶어서다. **첫날 30분 안에 원생을 다 등록하지 못하면 나는 이 앱을
지운다.** 그 감각으로 테스트한다.

- 계정: `qa.owner@pawlog.test` / `QaTest1234!`
- 시작: `https://pawlog-dev.doyeonism.com` → 로그인 → 자동 착지 지점 확인

## 이 세션에서 할 일

순서대로 한다. **앞이 실패해도 멈추지 말고**, 그 사실을 기록한 뒤 가능한 다음 항목으로 넘어간다.

### 1. 최초 진입 (약관 게이트)

- [ ] 로그인 직후 `/welcome` 으로 걸러지는가 (플랫폼 발급 계정은 약관 미동의 상태다)
- [ ] 약관 본문을 **다이얼로그로 열어 읽을 수 있는가** — 링크로 나가서 체크가 날아가면 버그
- [ ] 전체동의 체크박스가 개별 항목을 전부 켜는가
- [ ] 필수 약관을 하나 빼고 제출 → 막히는가, 무엇이 부족한지 **화면이 말해주는가**
- [ ] 전화번호를 **비우고** 통과되는가 (선택 항목이다). 건너뛰면 무엇을 잃는지 화면이 설명하는가
- [ ] 동의 후 `/app` 이 아니라 `/launch` 를 거쳐 착지하는가

### 2. 매장 개설

- [ ] 소속이 0개인 상태에서 `/app` 에 착지하는가
- [ ] 개설권 없이 매장 개설 시도 → 막히는가. **무엇을 사야 하는지 화면이 안내하는가**
- [ ] 개설권 구매 (dev 는 결제 없이 발급된다) → 성공 후 화면이 **스스로 갱신되는가**
      (새로고침해야만 반영되면 기록한다 — job-054 부류다)
- [ ] 매장 개설: 이름 `QA유치원`, 서브도메인 `qa-school`
- [ ] 서브도메인 중복 검사가 **입력하는 동안** 도는가
- [ ] `pet`, `app`, `admin` 같은 이름을 넣으면 어떻게 되는가
- [ ] 개설 후 `/tenant/qa-school` 로 이동하는가

### 3. 원생 등록 — 이 앱의 첫날 관문

가장 중요한 구간이다. **세 갈래를 전부 태운다.**

- [ ] 전화번호 `01011110003` (이보호자, 계정 있음) 조회 → 회원으로 잡히는가
- [ ] 그 보호자의 새 아이 `QA초코` 등록 (믹스, 5kg)
- [ ] 전화번호 `01099998888` (계정 없음) 조회 → **계정 없이 등록 가능한가**
- [ ] `QA두부` 등록 → 원생 목록에 **"계정 미연결 + 등록된 연락처"** 로 보이는가
      (빈칸이면 버그다 — 그 아이가 가입 유도 대상이라 원장이 여기서 알아야 한다)
- [ ] 전화번호를 **하이픈 넣어서** `010-1111-0003` 입력 → 같은 사람으로 매칭되는가
- [ ] 프로필 사진 업로드 → **원생 목록에서 실제로 보이는가** (여기가 job-055 가 터진 자리다.
      네트워크 200 이 아니라 `<img>` 가 그려졌는지를 본다)

### 4. 안전 정보 — 카드 표면에 올라오는가

`QA초코` 수정 → **맨 위** 안전정보 섹션에서:

- [ ] 알러지 `닭고기` 추가 → 원생 카드 **표면에** 배지로 뜨는가
- [ ] 공격 이력 체크 → 카드 **테두리가 승격**되는가 (배지만 바뀌면 부족하다. 테두리는
      지나가면서도 보여야 한다)
- [ ] 접종 만료일을 **어제 날짜**로 넣기 → `주의`/`만료` 로 뜨는가
- [ ] 접종 기록을 **아예 비우기** → `정상` 이 아니라 `주의` 로 뜨는가
      ("확인했고 문제없다"와 "아무도 확인한 적 없다"가 같아 보이면 critical 이다)
- [ ] 성향에 `대형견 무서워함` 입력 → 저장·표시되는가

### 5. 오늘 화면 (대시보드)

- [ ] `/tenant/qa-school` 이 **메뉴판이 아니라 오늘**을 보여주는가
- [ ] 5블록이 **동시에** 뜨는가 — 블록마다 로딩이 따로 끝나 순서가 뒤바뀌면 기록한다
- [ ] 등원 현황에 **미도착 아이 이름**이 나오는가 (숫자만이면 부족하다)
- [ ] "오늘 주의할 아이"에 §4에서 만든 아이들이 올라오는가
- [ ] 픽업 타임라인이 **시각 순**인가

### 6. 요금제 · 이용권 · 매출

- [ ] 요금제 만들기: `QA 10회권` (COUNT, 10회, 유효기간 30일)
- [ ] `QA초코` 에게 이용권 판매 → **잔여 10회**가 뜨는가
- [ ] 현장 현금 결제로 기록 → 매출 화면에 반영되는가
- [ ] 환불 → 매출이 **차감**되는가, 이용권 잔여는 어떻게 되는가
- [ ] 잔여 0회인 아이를 등원 체크하면 어떻게 되는가 (음수로 내려가면 critical)

### 7. 구성원 초대

- [ ] `qa.staff@pawlog.test` 를 **STAFF** 로 초대
- [ ] `qa.guardian@pawlog.test` 를 **GUARDIAN** 으로 초대
- [ ] 초대 목록에 대기 상태로 보이는가
- [ ] (세션 2·3에서 상대가 수락한다)

### 8. 등원 되돌리기 — 놓치기 쉬운 곳

- [ ] `QA초코` 등원 체크 → 이용권이 **1회 깎이는가**
- [ ] 토스트의 **되돌리기가 8초간 살아 있는가** (측정한다)
- [ ] 되돌리기 → 상태와 **차감이 함께** 되돌아오는가 (잔여가 10으로 복귀하는지 눈으로 확인)
- [ ] 토스트가 알림톡은 회수 못 한다는 사실을 **밝히는가**
- [ ] 되돌린 뒤 다시 등원 체크 → 차감이 정상적으로 다시 일어나는가 (건너뛰면 버그)

## 반드시 함께 볼 것

- **모바일 뷰포트(390×844)로 본다.** 이 사람은 데스크톱을 쓰지 않는다.
- 버튼이 **64px 이상**인가. 하나라도 44px 대가 보이면 측정해서 기록한다.
- **15px 미만 글자**가 있는가.
- 뮤테이션 후 목록이 **새로고침 없이** 바뀌는가. 매번 확인한다.
- 빈 상태에 **다음 행동 버튼**이 있는가. "없어요"만 있으면 기록한다.

## 하지 말 것

- 기존 데이터(`*@test.local`, `default` 테넌트)를 지우지 않는다.
- 코드를 읽어 원인을 진단하지 않는다. 본 것만 기록한다.
- 막혔다고 API 를 직접 호출해 우회하지 않는다 — **막혔다는 것이 결과다.**
