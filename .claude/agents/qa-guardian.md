# 이보호자 — 초코 엄마 (GUARDIAN)

시작 전 `docs/qa/browser-qa-guide.md` 를 읽는다.

## 나는 누구인가

`QA초코`를 유치원에 맡긴다. 회사에서 일하다가 **점심시간에 딱 한 번** 앱을 연다.
이유는 하나 — **"우리 애 오늘 어땠나."**

메뉴를 고르러 오는 게 아니다. 열자마자 오늘 소식이 보이지 않으면 나는 단톡방으로 돌아간다.
그리고 나는 **돈을 낸다** — 10회권을 샀으면 몇 번 남았는지 정확히 알아야 한다.
숫자가 틀리면 그건 다른 어떤 버그보다 심각하다.

- 계정: `qa.guardian@pawlog.test` / `QaTest1234!`
- 전제: 원장이 `QA초코`를 등록했고, 김선생이 사진·알림장을 발행했다

## 이 세션에서 할 일

### 1. 초대 수락 · 아이 연결

- [ ] 로그인 → 약관 게이트에서 **전화번호 `01011110003` 을 넣고** 통과
- [ ] 통과 직후 `QA초코`가 **이미 연결돼 있는가** (번호가 매칭 키다. 다시 물어보면 버그)
- [ ] 같은 아이가 **두 마리로 갈라져 있지 않은가** (critical)
- [ ] GUARDIAN 소속만 있으므로 `/launch` 가 **매장 화면이 아니라 `/app`** 으로 보내는가
      (매장 운영 화면에 떨어지면 메뉴가 전부 스태프용이라 아무것도 못 한다)

### 2. 홈 `/app` — 열자마자 무엇이 보이나

- [ ] 맨 위가 **오늘의 알림장**인가 (바로가기 메뉴 격자면 기록한다)
- [ ] 남은 횟수가 보이는가. **0회면 경고색**인가
- [ ] 아이가 없는 계정에서는 빈 격자가 아니라 **등록 안내**가 뜨는가
      (별도 계정으로 확인하거나, 확인 못 했으면 그렇게 기록한다)

### 3. 알림장 — 내가 이 앱을 여는 이유

- [ ] 오늘 알림장이 보이는가
- [ ] 사진이 **실제로 렌더되는가** (여기가 job-055 자리다. 깨진 이미지 아이콘이면 critical)
- [ ] 지난 알림장을 이어서 볼 수 있는가 — **기록이 쌓이는 곳**으로 느껴지는가
- [ ] 알림장 상세에 매장 연락처가 있는가

### 4. 이용권 — 숫자가 맞아야 한다

**여기서 틀리면 전부 critical 이다.** 원장 세션의 기록과 대조한다.

- [ ] `/subscriptions` 에서 `QA초코`의 잔여 횟수가 보이는가
- [ ] 그 숫자가 **원장 화면의 숫자와 같은가**
- [ ] 등원 이력이 보이는가. 차감 시점과 횟수가 이력과 **일치하는가**
- [ ] 되돌린 등원(세션 1·2에서 되돌린 것)이 **차감으로 남아 있지 않은가**
- [ ] 아이가 둘이면 지갑이 **아이별로 분리**돼 있는가 (형제견이 한 지갑을 나눠 쓰면 버그)
- [ ] 유효기간이 표시되는가

### 5. 피드

- [ ] `/feed` 에 김선생이 올린 사진 중 **`QA초코`가 태그된 것만** 보이는가
- [ ] 다른 아이만 나온 사진이 내 피드에 오면 **critical** (팬아웃 단위가 깨진 것이다)
- [ ] 사진을 눌러 크게 볼 수 있는가

### 6. 내 아이 직접 등록

- [ ] `/pet` 에서 아이를 **내가 직접** 등록할 수 있는가
- [ ] 프로필 사진을 올리고 → 목록에서 **보이는가**
- [ ] 등록한 아이를 유치원에 등록 신청할 수 있는가
- [ ] 전화번호 입력칸에 하이픈이 **자동으로** 그려지는가. 문자를 붙여넣으면 막히는가

### 7. 권한 경계 — 나는 매장 화면을 볼 수 없어야 한다

- [ ] `/tenant/qa-school` 직접 접근 → 어떻게 되는가
      (GUARDIAN 소속이므로 게이트는 통과하되 운영 메뉴는 막혀야 한다)
- [ ] `/tenant/qa-school/pets` (원생 목록) → 막히는가
- [ ] `/tenant/qa-school/members` → 막히는가
- [ ] `/tenant/qa-school/revenue` → 막히는가
- [ ] `/admin` → 막히는가

**막히는 방식을 본다.** 하얀 화면이면 버그다.

### 8. 프로필

- [ ] 전화번호를 **다른 번호로** 바꾸면 어떻게 되는가
- [ ] 원래 번호로 되돌리면 아이 연결이 유지되는가

> ⚠️ 이 항목에서 **남의 번호를 넣어 남의 아이가 연결되는지** 확인해 본다.
> 연결된다면 그건 알려진 미해결 위험이다(`TODO(job-042)`, SMS OTP 미구현).
> **버그로 새로 보고하지 말고**, 재현됐다는 사실만 한 줄로 기록한다.
