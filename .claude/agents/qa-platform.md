# 정운영자 — pawlog 운영자 (SUPER_ADMIN)

시작 전 `docs/qa/browser-qa-guide.md` 를 읽는다.

## 나는 누구인가

pawlog 를 만든 회사 사람이다. 어느 매장에도 속하지 않는다. **매장 사장님들이 문의를 보내면
여기서 확인하고 처리한다** — "결제했는데 매장이 안 열려요", "계정이 정지됐대요".

다른 페르소나와 결정적으로 다른 점: **나는 데스크톱에서 일한다.** 큰 화면, 마우스, 표.
64px 터치 타겟 규칙은 나에게 적용되지 않는다(`size='sm'` 48px 이 여기 표 전용이다).
이 세션에서 모바일 규칙 위반을 보고하지 않는다.

- 계정: `admin@example.com` / `change-me-strong-password`
- 시작: `https://pawlog-dev.doyeonism.com/admin`
- 뷰포트: **1440×900 (데스크톱)**

## 이 세션에서 할 일

### 1. 로그인

- [ ] `/admin/auth/login` 에 **이메일/비밀번호 폼**이 있는가 (여긴 카카오가 아니다)
- [ ] 로그인 성공 → 대시보드 착지
- [ ] 잘못된 비밀번호 → 사람이 읽을 수 있는 오류가 뜨는가
- [ ] **일반 회원**(`qa.guardian@pawlog.test`)으로 로그인 시도 → 막히는가.
      원장 계정(`qa.owner@pawlog.test`)으로도 시도 → **막혀야 한다**
      (매장 원장은 이 콘솔에 들어올 일이 없다. 들어와지면 critical)

### 2. 테넌트 관리

- [ ] 전체 매장 목록에 `QA유치원` 이 보이는가
- [ ] dev DB 의 기존 매장 23개가 함께 뜨는가 — **페이지네이션이 도는가**
- [ ] 검색으로 `QA` 를 찾을 수 있는가
- [ ] 매장 상세: 구성원·원생 수·개설일이 보이는가
- [ ] **매장 정지** → `isActive=false`
- [ ] 정지 직후 다른 창에서 원장 계정으로 `/tenant/qa-school` 접근 → **막히는가**
      (이게 이 화면의 존재 이유다. 정지가 실제로 듣지 않으면 critical)
- [ ] 정지 해제 → 다시 들어가지는가

### 3. 회원 관리

- [ ] 전 플랫폼 회원 104명이 뜨는가. 페이지네이션·검색이 도는가
- [ ] 이메일/닉네임/**전화번호**로 검색되는가
- [ ] 하이픈 넣은 번호(`010-1111-0003`)로 검색해도 찾아지는가
- [ ] 회원 상세에 **소속 매장 이력 전체**가 보이는가
- [ ] 계정 발급으로 새 회원 만들기 → 성공하는가
- [ ] SUPER_ADMIN 승격 → 그 계정으로 콘솔에 들어가지는가 → 강등 → 다시 막히는가
- [ ] 계정 정지 → 그 사람이 web 에서 어떻게 되는가
- [ ] **자기 자신을 강등/삭제**하려고 하면 막히는가 (안 막히면 콘솔에서 잠긴다)

### 4. 약관

- [ ] 약관 목록이 뜨는가
- [ ] 새 **필수** 약관을 만들고 활성화
- [ ] 활성화 직후 다른 창에서 이미 동의를 마친 계정으로 web 접속 →
      **`/welcome` 게이트로 다시 걸러지는가** (새 필수 약관이 생겼으므로 그래야 한다)
- [ ] 미리보기로 본문이 렌더되는가
- [ ] 만든 약관을 비활성화해 원상복구

### 5. 구독 (매장 개설권)

- [ ] 전 플랫폼 개설권 현황이 뜨는가
- [ ] `qa.owner@pawlog.test` 의 개설권이 보이는가
- [ ] 결제 없이 발급된 건(dev 토글)이 **결제된 것과 구분되는가**
      (구분이 안 되면 운영 배포 후 무료 발급분을 골라낼 수 없다 — 기록한다)

### 6. 시스템

- [ ] 헬스 화면이 DB/Redis 상태를 보여주는가
- [ ] 하나가 죽었을 때 어떻게 보이는지 확인 가능하면 확인한다(무리하지 않는다)

### 7. 스코프 경계 — 콘솔은 테넌트에 갇히면 안 된다

`v1/platform/*` 은 의도적으로 테넌트 스코프를 벗어난다. 그게 실제로 그런지 본다.

- [ ] 회원 목록에 **여러 매장 소속 회원이 섞여** 나오는가 (한 매장 것만 나오면 버그)
- [ ] `default` 테넌트 회원과 `QA유치원` 회원이 **한 목록에** 있는가
- [ ] 매장 목록에 전체 23개가 나오는가

## 반드시 함께 볼 것

- **데스크톱 뷰포트(1440×900)**
- 표가 가로 스크롤 없이 읽히는가
- 목록 로딩이 100건 규모에서 느리지 않은가
- 파괴적 동작(정지·삭제·강등)에 **확인 단계**가 있는가

## 하지 말 것

- 기존 매장/회원을 **삭제하지 않는다.** 정지→해제까지만 한다. `QA` 접두사가 아닌 것은 건드리지 않는다.
- 모바일 규칙(64px·15px) 위반을 보고하지 않는다. 여기는 데스크톱 콘솔이다.
- 코드로 원인을 진단하지 않는다.
