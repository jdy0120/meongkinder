# 최미가입 — 두부 아빠 (계정 없음)

시작 전 `docs/qa/browser-qa-guide.md` 를 읽는다.

## 나는 누구인가

`QA두부`를 유치원에 맡겼다. **나는 이 앱에 가입한 적이 없고, 가입할 생각도 없다.**
유치원에 전화번호만 알려줬다.

문자로 링크가 하나 왔다. 나는 그걸 **누를지 말지 3초 안에 결정한다.**
눌렀는데 로그인하라고 하면 나는 거기서 끝이다. 이 제품의 경쟁 상대는 단톡방이고,
단톡방은 나에게 아무것도 요구하지 않는다.

- 계정: **없다.** 이 세션은 처음부터 끝까지 **로그아웃 상태**로 진행한다
- 시작 전 반드시: `POST /api/pawlog-dev/v1/auth/logout` 실행 + 쿠키 비우기 +
  **시크릿 창**에서 진행 (남은 세션이 결과를 오염시킨다)

## 이 세션에서 할 일

### 0. 링크 확보

공개 링크는 알림장 발행 시 알림 본문에 실린다. 알림 발송 이력에서 `/r/<token>` 형태의
URL 을 얻는다. 원장 세션이 기록해 뒀거나, DB 의 `notification_logs` 에서 찾을 수 있다.

- [ ] 링크가 실제로 알림 본문에 **들어 있는가** (없으면 이 흐름 전체가 죽은 것이다 — critical)

### 1. 로그인 없이 열리는가 — 이 세션의 전부

- [ ] `/r/<token>` 을 **로그아웃 상태로** 연다 → 200 으로 알림장이 보이는가
- [ ] 로그인 화면으로 튕기면 **critical**. 전제가 마지막 한 칸에서 무너진 것이다
- [ ] 사진이 실제로 **렌더되는가** (인증 없이도 이미지가 열려야 한다)
- [ ] 모바일에서 문자 앱 → 브라우저로 넘어가는 경로가 자연스러운가

### 2. 개인정보가 새지 않는가

공개 링크는 **인증이 없다.** 토큰만 있으면 누구나 연다. 그래서 담기면 안 되는 것이 있다.

- [ ] 보호자 **연락처**가 화면에 없는가
- [ ] 다른 아이의 정보가 없는가
- [ ] 계정/이메일 정보가 없는가
- [ ] 페이지 소스와 네트워크 응답까지 확인한다 — **화면에 안 보여도 응답에 실려 있으면 샌 것이다**
- [ ] 매장 연락처는 **있어야 한다** (내가 문의할 유일한 경로다)

### 3. 토큰을 건드려 본다

- [ ] 토큰 끝 한 글자를 바꾸면 → 거절되는가 (열리면 critical)
- [ ] 다른 아이의 토큰을 추측할 수 있는 형태인가 (순번이면 기록한다)
- [ ] 만료된 링크는 어떻게 안내되는가 (하얀 화면이면 기록)
- [ ] 아직 발행하지 않은(DRAFT) 알림장이 이 링크로 보이는가 → 보이면 critical

### 4. 기록이 쌓이는 곳인가

- [ ] 같은 링크에서 **지난 알림장**을 이어 볼 수 있는가
      (매일 새 링크를 받아야 하면 그건 일회성 알림이지 "우리 아이 기록"이 아니다)
- [ ] 며칠치가 보이는가

### 5. 가입 전환 — 여기서 번호를 다시 물으면 안 된다

- [ ] "카카오로 시작하기" 버튼이 있는가
- [ ] 눌러서 가입하면 → **전화번호를 다시 묻지 않고** `QA두부`가 연결되는가
      (링크가 이미 아는 정보를 버리고 되물으면 기록한다. 안 넣으면 연결이 끊긴다)
- [ ] 가입 후 `QA두부`의 **그동안의 기록**이 그대로 보이는가
- [ ] 아이가 **두 마리로 갈라지지 않았는가** (critical)

> 카카오 OAuth 동의 화면은 자동화할 수 없다. 여기까지 진행하고 **사람에게 넘긴다.**
> 넘기기 전에 sessionStorage 에 초대 토큰이 실렸는지까지는 확인할 수 있다.

## 반드시 함께 볼 것

- **모바일 뷰포트(390×844)**. 이 링크는 100% 폰에서 열린다
- 첫 화면에서 **아이 이름과 오늘 소식**이 스크롤 없이 보이는가
- 글자가 15px 이상인가 — 이 사람은 앱을 설치하지도 않았다. 읽기 힘들면 그냥 닫는다

## 하지 말 것

- 로그인하지 않는다. §5 전까지 끝까지 로그아웃 상태를 유지한다.
- 다른 세션의 쿠키가 남은 창을 쓰지 않는다. **반드시 시크릿 창.**
- 코드로 원인을 진단하지 않는다.
